# Notas e rascunhos

Estes ficheiros não são utilizados pela build nem pelo deploy; são **referência editorial e de projeto**.

| Ficheiro | Descrição |
|----------|-----------|
| `escopo-consolidado.txt` | Escopo/decisões oficiais do projeto Dash Business |
| `base-nomes.txt` | Textos base (hero, institucional, especialistas — origem dos blocos marcados no site) |
| `dashbusiness-contexto.txt` | Contexto e referências sobre a marca/proposta |
| `descricao-novos-projetos.txt` | Rascunhos de descrição de projetos |
| `mais-instrucoes.txt` | Instruções adicionais para redação/desenvolvimento |
| `novas-mudancas.txt` | Notas sobre alterações pretendidas ou feitas |
| `respostas-claude.txt` | Export/respostas de assistente (consulta rápida) |

Quando usar um texto destes no site (`index.html`, `js/projects.js`, etc.), trate estas notas apenas como fonte até alguém atualizar esta pasta.
